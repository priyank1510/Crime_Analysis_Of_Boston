# F-A-I
We propose to address the problem of rising crime rates and inefficient crime management strategies in urban areas. The primary goal is to develop a  framework that utilizes machine learning and natural language processing techniques to predict crime rates, identify crime hotspots, and analyze  sentiment towards crime and safety. 



We have used XGBoost cluster for creating the type of crime in boston it consist of 4 levels and based on crime severity classification occurs. 
In order to better understand the crime related data of boston we have integrated clustermap  that shows the portion on map where and how the level crime is and how the crime changes based on time.
